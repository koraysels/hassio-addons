# Decypharr

Home Assistant add-on for [Decypharr](https://github.com/sirrobot01/decypharr): a media
gateway that pretends to be a qBittorrent client for Sonarr and Radarr and sends every
grab to your debrid account (TorBox, Real-Debrid, AllDebrid, Debrid-Link, Premiumize).

Wraps [`cy01/blackhole`](https://hub.docker.com/r/cy01/blackhole).
Supports `amd64`, `aarch64`. See [DOCS.md](DOCS.md) for setup.
