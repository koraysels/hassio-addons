# Koray's HA Add-ons

A Home Assistant addon repository.

## Installation

1. In Home Assistant: **Settings → Add-ons → Add-on Store → ⋮ → Repositories**
2. Add `https://github.com/koraysels/hassio-addons`
3. The addons below will appear in the store

## Addons

### [Calibre-Web Automated](calibre_web_automated/)

Automated Calibre-Web with ebook ingestion and a clean web interface. Drop ebooks into an
ingest folder and they are automatically imported into your Calibre library with metadata.

Wraps [`crocodilestick/calibre-web-automated`](https://github.com/crocodilestick/Calibre-Web-Automated).
Supports `amd64`, `aarch64`, `armv7` · HA Ingress on port `8083`.
