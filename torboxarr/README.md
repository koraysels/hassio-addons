# TorBoxarr

Home Assistant add-on for [TorBoxarr](https://github.com/MrJoiny/TorBoxarr): pretends to be
qBittorrent **and** SABnzbd, so Sonarr and Radarr can send torrents and NZBs (usenet) to
TorBox.

Wraps [`mrjoiny/torboxarr`](https://hub.docker.com/r/mrjoiny/torboxarr).
Supports `amd64`, `aarch64`. See [DOCS.md](DOCS.md) for setup.
